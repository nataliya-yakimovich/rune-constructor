# rune-constructor

Конструктор рун: статический сайт (HTML + CSS + JS) для GitHub Pages. Работает на телефоне и компьютере.

## Возможности

- Меню (кнопка слева сверху): «Сохранить в PNG», фон листа, соотношение сторон, список рун, «Очистить лист».
- Руну можно перемещать, менять размер (уголок рамки или слайдер), цвет, толщину линий, копировать и удалять.
- Отменить / Вернуть — до 100 шагов (Ctrl+Z, Ctrl+Y / Ctrl+Shift+Z).
- Состояние и история сохраняются в `localStorage` — работу можно продолжить позже.
- «Очистить лист» удаляет все руны и возвращает белый фон; история сохраняется, очистку можно отменить.

## Как добавить руну

1. Положите SVG-файл в папку `runes/`, например `runes/uruz.svg`.
2. Добавьте запись в `runes/runes.json`:

   ```json
   { "id": "uruz", "name": "Уруз", "file": "uruz.svg" }
   ```

Требования к SVG:

- у корневого `<svg>` должен быть `viewBox`, плотно обрезанный вокруг руны (≈2 единицы отступа);
- линии рисуются обводкой (`stroke`), без `fill`;
- не задавайте `stroke`, `stroke-width` и `fill` у отдельных `<path>` — иначе цвет и толщина не будут меняться.
  `stroke-width` у корневого `<svg>` задаёт толщину руны по умолчанию.

`id` — латиницей и не меняйте его у существующих рун: по нему руны восстанавливаются из сохранения.

## Локальный запуск

Сайт загружает руны через `fetch`, поэтому открывать `index.html` двойным кликом нельзя — нужен веб-сервер:

```bash
npx http-server -p 8080
```

и откройте http://localhost:8080.

## Публикация

Settings → Pages → Deploy from a branch → `main` / `(root)`.
